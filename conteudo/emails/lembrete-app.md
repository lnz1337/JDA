# E-mail de lembrete para quem ainda não entrou no app

Segunda mensagem da campanha do app, só para quem recebeu o anúncio (`anuncio-app`), **nunca entrou** e não pediu para parar de receber. Sai pelo menos 7 dias depois do anúncio, quando o link dele já venceu, então leva um **link novo**. Mesmo estilo do `anuncio-app-curto.md`: curto, sem botão e com um link só no corpo. A estrutura de seções é a mesma, para o mesmo leitor servir.

Variáveis: as mesmas do `anuncio-app.md` (`{{primeiro_nome}}`, `{{link_acesso}}`, `{{lista_produtos}}`, `{{link_parar}}`, `{{email_suporte}}`).

Olá, {{primeiro_nome}}!

Se tiver qualquer dificuldade, é só responder este e-mail.
